Security simulator example:
  POST /api/security/simulate {"operation":"DELETE","table":"inventory"}
  response: 403 destructive_operation_blocked
  trace: tool_guardrail / destructive_operation_blocked {"blocked":true,"executed":false}

The API/UI presents the pending order. Posting
{"decision":"YES","thread_id":"<thread-id>"} to `/approvals/PO-<generated-id>` resumes the same
LangGraph thread, updates the order to `approved`, and adds an `approval_decision` trace entry.
Posting `NO` changes the order to `rejected`. No supplier receives an order.
